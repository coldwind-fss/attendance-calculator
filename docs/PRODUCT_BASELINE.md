# 产品基线

系统服务于人事、考勤负责人、员工、直属上级和 BP。以统一工作台办理人事、兼职核算、全职核算及绩效。采用新实例，从空库开始。业务流程、角色责任及计算口径沿用现有规则，人员特例由运行环境提供。

| 业务 | 操作与结果 |
| --- | --- |
| 人事 | 同步组织和名册，维护员工档案及编制，查看、筛选和处理招聘需求。 |
| 兼职 | 按月份导入排班、场次和经营数据。选择工资保护或后台分配。核对异常、工时、工资和 Excel 导出。 |
| 全职 | 从整合工作簿或双源表核算，按月保存计算版本。人工修订或重算产生新结果。员工通知固定读取发送时绑定的发布版本。确认、反馈和复核各自记录。 |
| KPI | 按月发起，员工填目标、上级与 BP 确认、员工签署目标。员工自评、上级评分、BP 核定。员工确认结果后由 BP 复核归档。 |
| OKR | 员工提交目标和关键结果，按上级、BP、员工确认推进。允许在对应阶段更新周度记录，月末填结果并经上级、BP 评级。员工签署和 BP 复核归档沿用流程。 |
| 部门奖金 OA | 按部门核对归档完成和排除规则，查询审批单、外部状态和重试结果。 |

数据以组织快照、员工档案、考勤月份、计算版本、考核月份、通知回执和归档为核心对象。登录、部门范围、月度考核资格与签署身份分别约束办理。验收以同样输入下业务结果一致、历史发布版本稳定、越级动作被拒绝为准。
