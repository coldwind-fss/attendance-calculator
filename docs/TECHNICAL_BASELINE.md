# 技术基线

Vue 3 和 FastAPI 同源提供工作台和业务接口。Python 负责考勤及绩效规则，Node 适配 Excel 与绩效办理、签署和外部接口。适配器由 FastAPI 调用，绩效兼容服务只监听本地端口。

| 边界 | 职责与存储 |
| --- | --- |
| 演示会话 | 自动建立匿名浏览器会话，关联上传与作业并提供写入 CSRF 校验。 |
| 人事 | SQLite 保存组织快照、档案、编制和招聘。 |
| 兼职 | 上传登记、按月作业、结果及 XLSX 下载。 |
| 全职 | Python 引擎、SQLite schema 7、工作簿及版本指针。发布与外部通知分开提交。 |
| 绩效 | 角色待办、KPI 算分、OKR 状态、签署与归档。兼容进程承接签署审计、部门 OA 和现有文件存储。 |
| 作业与事件 | SQLite 事务保存作业、业务写入和已实现的事件。全职工作台可按月份和游标补读。 |

`/api/v1` 提供管理 API，`/api/public/v1` 提供员工考勤接口。请求与响应字段由 `/openapi.json` 定义，事件信封和载荷由 `/api/v1/event-schema` 定义。绩效兼容入口在 `/hrms/performance`，部门权限及已签署状态由流程服务判定。

依赖由锁文件固定，运行数据目录与发布版本目录分开。发布通过安装脚本构建、回归、服务就绪检查和版本回退。新环境以空数据库启动，环境和业务策略单独配置。
