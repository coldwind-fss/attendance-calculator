# 环境与业务策略

新实例启动时从 `HR_DATA_DIR` 读取运行数据。管理员账号通过 `HR_ADMIN_USERNAME` 和 `HR_ADMIN_PASSWORD` 配置。正式 HTTPS 入口配置 `HR_PUBLIC_BASE_URL`，钉钉外发及绩效 OA 分别通过 `HR_ENABLE_DINGTALK_DELIVERY` 和 `HR_ENABLE_PERFORMANCE_EXTERNAL` 启用。示例环境文件见 [部署目录](../deploy/workbench.env.example)。

`HR_COMPANY_POLICY` 指向运行环境提供的 JSON 文件。三个顶层对象可以按需填写。省略的人员特例为空，通用计算规则继续由代码执行。

| 对象 | 可配置项 |
| --- | --- |
| `parttime` | `PERSON_RATES`、`ALIASES`、`PERSON_REAL_NAMES`、`DISPLAY_ALIASES`、`SPORTS_XHS_ONLY_PEOPLE`、`SETTLEMENT_PROTECTION_TARGETS`、`DEFAULT_SETTLEMENT_ORDER`、`DEFAULT_PAYROLL_ORDER`、`DEFAULT_OPERATOR_USER_ID`、`PERSON_ALIASES`、`REAL_NAME_TO_ALIAS` |
| `fulltime` | `NO_OVERTIME_NAMES`、`ATTENDANCE_GROUP_BY_NAME`、`FULL_MONTH_INACTIVE_NAMES`、`RESIGNED_NAMES`、`PAYROLL_DIRECT_NAMES`、`PAYROLL_FIXED_DAYS`、`SCHEDULED_DAYS_BY_NAME`、`SPECIAL_REST_WEEKDAYS_BY_NAME`、`STANDARD_DOUBLE_REST_NAMES`、`WIFI_MACS`、`COMPANY_LOCATION_KEYWORDS`、`WIFI_EXCLUSIONS`、`NINGBO_FULL_ATTENDANCE_NAMES`、`SPECIAL_REST_COMPENSATION_NAMES` |
| `performance` | `EMPLOYEE_ROSTER`、`DEFAULT_EMPLOYEE_OVERRIDES`、`GLOBAL_ADMIN_NAMES`、`BP_SCORER_NAMES`、`DEPARTMENT_ACCESS_BY_NAME`、`HRBP_BY_DEPARTMENT`、`DEFAULT_BP_NAME`、`OKR_ELIGIBLE`，以及组织重命名和 OA 分组配置 |

空配置示例为 `{"parttime": {}, "fulltime": {}, "performance": {}}`。钉钉应用凭据、AI 表和通知渠道通过各自环境变量及配置文件提供。绩效签署需要真实人员名册及可用的钉钉验证码通道。
